# Exp14 E0/E1-FULL 正式实验预注册

`EXP14_FORMAL_PROTOCOL_READY_PENDING_CHATGPT_GATE`。本阶段冻结协议、代码、数据和初始化身份。执行 100 轮训练、执行冻结 VAL 及追加控制各需相应授权。

## 研究问题与主要比较

保持 668 张原始 TRAIN 和原标注各完整训练 100 轮，检验加入 379 张经人工确认、通过 A10 空标签审查的伪正常图对七类实例分割的影响。两臂独立从冻结 COCO 权重建立七类 YOLO11n-seg，使用相同类别和 VAL，复用一种固定模型架构与原生损失。E0 每轮只遍历 668 张原图，E1-FULL 每轮遍历 668 张原图及 379 张修复图。轮内原生随机无放回，顺序逐轮固定，尾批保留。两臂各消费原图及其监督 100 轮。单图扩展、裁切等增强可使部分实例出界，两臂分别记录增强前和增强后计数。

E1-FULL 在等轮数下多 1,200 次计划更新。原始样本的批内同伴与随机增强随各臂抽样而变，增强后实例曝光、实测时间、显存峰值和学习率轨迹随运行记录。主效应涵盖增加这批数据后自然产生的计算预算变化。

## 训练配置与数值规则

- 以 A11-1 通过的配置为基础。640 输入，batch 32、nbs 32、累积 1、seed 42、两名 worker。AdamW，LR 0.01、lrf 0.01、momentum 0.937、weight decay 0.0005、裁剪上限 L2 10。FP32 主参数与 CUDA AMP。保留单图平移、缩放、水平翻转和 HSV 增强。关闭 mosaic、MixUp、CutMix、Copy-Paste、多尺度与矩形组批。正式版固定了每轮的排列和 worker 生成器种子，便于从轮边界可追溯恢复。它不要求重现 Smoke 的持久迭代器抽样顺序。
- 原生线性 epoch 调度以 100 轮为分母，零基 epoch `e` 的系数为 `(1-e/100)*(1-lrf)+lrf`。原生三轮 warmup 以各臂真实批数计，E0 为 63、E1 为 99 个零基迭代位置。在 warmup 内，偏置 LR 从 0.1、其余可训练组从 0 插值到相应 epoch 的目标。正式执行发布逐批 LR、warmup 边界及 scheduler 状态。两臂遵循同一公式，各自在 3 轮内完成 warmup。
- GradScaler 初始 Scale 1、增长因子 2、增长间隔 2,000、退避因子 0.5。无跳步时，第 2,000 次有效更新后由 1 升到 2，E0 在第 96 轮第 5 批，E1 在第 61 轮第 20 批。Scale 2 从下一批起参与计算，最终增长计数应分别为 100、1,300。A11-1 仅覆盖前 50 次、均在 warmup 内。记录 loss 各分量、梯度、主参数、EMA、优化器、Scale、步进尝试和原生调用、有效更新，以及每轮实际曝光、显存和耗时。部分前景或分支梯度为零作为数值诊断记录。非有限值、原生跳步、无有效参数变化、计数或数据身份错误均为硬停止。
- 工程实现固定单卡、框架及预期硬件，记录 CUDA、权重和初始化。相同环境、相同主种子和同一轮种子规则支持复跑和轮边界恢复。跨驱动、GPU 或算子版本的位级等价没有实测保证。每臂分开启动并核对初始哈希。轮级 checkpoint 独立于 A10 和历次运行目录，默认每 5 轮落盘且保留原日志。终点固定使用第 100 轮 `last.pt` 的 FP32 主模型状态，遵循 A4-R1，EMA 随 checkpoint 存档。禁止按验证指标挑选训练中段权重。
- 只有分别达到计划的原生调用、有效更新、曝光、严格重载和一致数据核验，才可提交这对模型的正式比较。硬停止保留原始证据。恢复限有明确外部故障且有核对的完整轮 checkpoint，原路径保持只读，续跑独立写入，失败或回滚的实际算力和曝光与被接受的参数轨迹分开报告。恢复不复用 Smoke 或其他实验权重。

## 统一 VAL 方案

统一入口在两臂训练终点和独立授权之后运行。先对照冻结清单确认 VAL 154 张图、154 个标签、296 个实例，校验文件及符号链接目标。配置 `imgsz=640`、`conf=0.001`、`NMS IoU=0.70`、`max_det=300`、FP32，使用同一 Ultralytics 8.4.117 版本。主指标为 VAL Mask mAP50–95。同步报告 Mask mAP50、Box mAP50–95、原生 Mask Precision/Recall、七类各自 Mask AP50 与 AP50–95。

固定阈值统计以 `conf=0.25` 独立推理，NMS 和 max_det 相同。同类 Mask、Box 分别用 IoU≥0.50 构造配对，使用原生匹配的一对一去重。分别报告 TP、FP、FN。尺寸根据原尺寸图上的 GT Polygon 栅格面积和整图面积之比，复用早期 TRAIN 分位数 `0.0020196759259259256`、`0.007364969135802469`、`0.029209280303030303`，分成互斥 tiny、small、medium、large。按固定阈值 Mask 匹配报告各档召回与分母。没有匹配对象的统计显示为空。两臂都按相同阈值和相同推理配置运行，正式训练过程中和本阶段均不运行 VAL 或 TEST 推理。TEST 不用于本协议的训练、调参、选模或阶段决策。

## 后续控制与重复

E0-UPDATE 是另行授权的计算量控制。仅原始 668 图，按同一无放回规律完整跑 157 个原图 epoch（3,297 次），再用第 158 轮的前 3 个完整批，共 3,300 次。保留尾批，总原图曝光 104,972 张次，超出主 E0 38,172 张次。增强前正实例为 198,762 加上预注册排列的最后 96 张图的标签实例数。它采用 E1-FULL 的更新索引调度映射，虚拟 epoch 为 `floor(update_index/33)`，warmup 99 个位置，仍用原生 AMP 增长规则。如此可在固定 E1 更新轨迹预算下比较额外原图重复与加入修复图。它不参与主比较或本轮执行。

首轮 seed 42 作为诊断性配对。如需稳定效果结论，预先规划 seed 42、142、242 三组配对，通过独立 Gate 追加其余种子，报告逐种子主指标差、配对均值及变异。后续是否执行由预注册研究设计和实际资源决定，且不依据 TEST。
