## 数值停止证据

训练使用 D2 的 CUDA AMP、FP32 主参数、GradScaler init_scale=1 和原生 unscale、step、update。保留 AdamW、原 Loss、梯度裁剪 10、batch32、nbs32、accumulate1、冻结 LR 和增强。预设每批零梯度占比达到 1% 时记录分层统计，连续 3 批达到 5% 时停止。该规则和阈值在训练前写入入口和运行环境身份。

E0 的 926 批 loss、缩放及 unscale 后梯度、更新后的参数均有限，三个触发批也各有实际有效更新。总体 loss 范围为 108.170–503.923，裁剪前梯度范数为 33.44–6,267.15。119 个批次触发分层记录，峰值零梯度占比为 13.73%。终止窗口为：

| Epoch / Batch | 零梯度占比 | 裁剪前梯度范数 | Scale | 有效更新 |
| --- | ---: | ---: | ---: | --- |
| 42 / 22 | 9.8632% | 59.44 | 1 | 是 |
| 43 / 1 | 9.8463% | 114.59 | 1 | 是 |
| 43 / 2 | 9.8323% | 85.92 | 1 | 是 |

零梯度主要集中于框回归头 cv2 与掩码系数头 cv4。三个终止批的 cv2 各有 188,739 个零值，cv4 为 84,130–84,132。停止检查点在 CPU 严格重建后确认最粗尺度子分支 cv2.2、cv4.2 分别有 188,736 和 84,128 个参数。数量吻合支持检查该尺度是否缺少前景匹配。分层记录缺少逐子分支梯度和各尺度正样本分配，同批 FP32 对照也未执行，归因仍开放。
