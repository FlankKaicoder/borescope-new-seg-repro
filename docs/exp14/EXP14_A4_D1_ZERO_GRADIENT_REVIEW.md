## 历史证据与新诊断

原 A4 的 926 批均有有效 AdamW 更新，Scale 保持 1，溢出和跳步均为零。终止窗口的 `cv2` 和 `cv4` 零值数与最粗尺度 `cv2.2` 的 188,736 个参数和 `cv4.2` 的 84,128 个参数接近。原日志缺少各尺度 `fg_mask` 与预处理张量，无法直接确定历史三个触发批的前景分配。

新诊断从同一停止模型状态严格重载每一次反向，使用冻结 TRAIN 槽和独立确定的诊断种子构造输入。每个配对的预处理张量哈希一致，使用真实 FP32（关闭 autocast 和 TF32）及 CUDA AMP Scale=1，均执行原生分割损失。读取原生分配器的前景掩码，按三尺度 anchor 列区间计数。共 12 次反向、零参数更新。所有 Loss、梯度和梯度范数有限，主参数哈希保持一致。

步长 32 无前景的两批中，`cv2.2` 和 `cv4.2` 在两种精度下均全零，分类头仍收到梯度。其余四批的两条分支都有非零梯度，AMP 与 FP32 的最低余弦为 0.999712。最大 Loss 相对差为 0.105%。AMP 为零且 FP32 非零的位置最多占 FP32 全模型梯度 L2 范数的 0.00196%。这些结果支持条件性梯度稀疏，未发现影响优化的 AMP 下溢。三个位于历史停止位置的重构批次均有步长 32 前景，历史输入的精确归因仍有限。
