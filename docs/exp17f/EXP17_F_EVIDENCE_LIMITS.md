# Exp17-F independent current-asset and evidence audit

The independent audit confirms current byte identities and the frozen technical/evidence prerequisites. It does **not** grant Data Gate, create a human decision or train a model. The original 69-row user CSV, all Exp17-E files, historical A9/A10/D assets and prior results remain unchanged.

## Current bytes and frozen technical prerequisites

The audit rehashed 2,482 unique existing input files totaling 648,828,687 bytes, then rechecked them after the operation. This includes all 379 original TRAIN images, 379 professional JSONs, 379 selected A10 N assets, 379 published A10 N copies, 378 original-grid and 378 native-N Valid Masks, 192 available historical geometry files, and relevant Crop/Bounded parents, masks, requests and immutable metadata. Unique-byte counts are not total disk I/O: postchecking reads those bytes again. The run took 10.02 seconds.

No image was decoded or visually reassessed; no Polygon was rasterized, matrix fitted or support threshold changed. Current bytes must agree with the original A10 manifest and the exact Exp17-E mapping/lineage receipts. Published and selected N copies agree. Every source still binds one fixed current A10 N/version for all its Polygons.

The saved Raw-to-original affine, inverse direction, same-generation Raw identity and mapped Polygon coordinates were checked algebraically. Aligned assets stay on their already established original-source grid. Crop integer bounds/translation and parent identities remain intact. Bounded base/edit/request/parent identities remain intact. Missing mappings remain missing, with no fabricated N coordinates or paired local ROI.

All 65 actual user ACCEPT decisions match current-N/source/annotation/version metadata and pass the frozen mapping/full-support/identity prerequisites. Their original and native-N target counts remain complete. The eight prior technical exceptions remain outside the candidate pool. This revalidates the saved technical evidence; it does not create new pixel-level accuracy evidence or Formal TRE.

## Actual user decisions and evidence strata

The 69 decisions contain 65 ACCEPT and four REJECT. The rejects apply only to their exact Polygon/current-N identity. A source with a rejected Polygon is not rejected wholesale; the two accepted Polygons at the explicitly requested mixed-decision source remain accepted. Their notes and timestamps remain original user statements.

The independently recomputed candidate union is **499 inherited + 65 user ACCEPT = 564** Polygons in 373 source images / 353 independent groups. The 564/4/8 partition totals all 576 original records. The candidate pool comprises 521 Aligned, 38 Raw, four Crop and one Bounded regions.
