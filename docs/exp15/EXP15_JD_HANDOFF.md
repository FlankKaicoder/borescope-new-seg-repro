## 冻结阈值下的错误诊断

- **定位和 Mask。** 固定阈值的同类 Box TP 从 97 增至 102，Mask TP 从 95 增至 98。各臂原生 Box TP 对上的平均 Mask IoU 从 0.7283 升至 0.7447，配对集合由各自预测决定。Box TP 对上 Mask IoU 低于 0.50 的计数均为 6。达到正确类别和框门槛的命中增加，tiny 召回改善，而 large 召回下降。
- **分类。** 原生固定点 Mask 漏报按预先冻结次序归类，每个 GT 只进入一组。先记录同类合格 Mask 边但被一对一竞争排除，再记录仅有异类 Mask IoU≥0.50 的空间错配候选，然后是同类 Box 达标但 Mask 不达标、同类有重叠但低于门槛、完全无同类重叠。对应计数从 `0／2／6／25／168` 变为 `0／4／5／27／162`。异类空间错配候选增加 2 个。这些类别是诊断标签，依赖阈值与归类顺序。
- **低置信候选。** 从标准 pass 的 NMS 后结果一次性读取 `[0.001, 0.25)`。该区间预测从 16,766 增至 17,524，同区间的 Mask TP 从 89 增至 90，Box TP 从 129 降至 119。标准 pass 高分子集漏掉的 GT 中，存在至少一个同类低分 Mask IoU≥0.50 候选的计数从 89 增至 90。这一分段仅用于诊断候选，配对分母和原生 AP 的置信度排序各按对应规则计算。

本轮最清晰的收益体现在原生召回、固定点 Box 命中和整体 Mask AP50–95。分类空间错配和低分预测分段没有显示出同等幅度的改善。J-C 后期两个固定 TRAIN 批次的辅助梯度比分别为 189.6% 和 41.7%，本轮沿用训练时固定的 `λs=8` 与末轮模型。训练诊断和 VAL 结果各自保留，汇总指标不足以把变化归因到单一训练机制或外推跨种子效果。
