## 4. 不应传播的历史失败与源级标记

当前所选版本无用户拒绝，不代表其他版本从未失败。当前 Polygon 中有 158 个 / 99 组在**其他审核版本**曾要求 RETRY_REPAIR，123 个 / 90 组曾要求 RETRY_ALIGNMENT，两者并集 277 个 / 182 组；另 10 个 / 10 组在其他版本曾 HOLD。它们都保留为版本上下文，不能传播到当前精确所选版本。

122 个 Polygon / 37 组带 A9 源级版本标记，但不是 122 个当前版本身份错误。只有一个来源的两个 Polygon 分别采用不同已通过版本；各自绑定原 Aligned，计一个独立组，不拼接。未来真实加载器需解决同一 N 槽的版本一致性，不能在本轮偷偷统一版本或扩大样本数。

独立只读重放 A9 保存的元数据规则，复现 **639 个语义接受版本组合 = 555 个可用组合 + 84 个未列入可用组合**。84 涉及 82 个去重 Polygon / 57 组，与当前所选精确组合交集为零；其中四个 Polygon 在当前 545 中有另一个可用版本。当前清单外的已确认去重 Polygon 是 78 个，不是“当前 545 里面 84 个失败”。本轮不救回这些旧不合格组合，也不重新选择备选版本。

246 条旧几何文件缺历史整文件哈希，但保存矩阵、review/Aligned/Valid 绑定可追溯；这与错矩阵不同。保留其来源局限，不补造历史 SHA、不重新配准、不要求 G2。

## 5. 旧 G1 与新表的修正关系

历史 UI 的区域声明是“已确认通过区域可用于同源区域学习”。新 Exp17 十二项空字段、新 reviewer/time/boundary note 及 D0 的两边界站/位移试验，不是历史接受失效的理由。`independent_boundary_evidence` 不再被当作全量重新取点或 Formal TRE/G2 门槛。历史已明确比较同版机械部位和局部的记录，不要求用户重复证明。

展示 ROI 里另有 GT、触框、95%/90% 扩窗阈值、轻微纹理/亮度及非目标变化不自动否决。真正需处理的是错版本/错矩阵/目标无有效支持、明确未修复或结构幻觉、严重未解决 UI/FOV 捷径，以及其他缺陷进入**实际正常参照支持区域**。此前 175 个“另一 GT 在 ROI”只是风险信息，不证明目标池化受到污染。

12 个具体问题全部引用精确 review/Polygon 和原始证据：三条 ROI UI、六条目标状态或机械结构疑问、一条显著颗粒变化，以及两条全帧 UI 与实际区域/完整 N 输入范围的关系。它们是 Data Gate 的定点问题，**不是 12 条新用户 REJECT，也不自动撤销原 PASS**；能由已有范围和证据解释的直接闭环，不开展新一轮五轮视觉审核。此前六条 Codex HOLD 建议同样不能代替历史用户决定。
