## 特殊图的阅读规则

- **Heatmap/confusion matrix**：先说行列语义与是否归一化，再找对角线和主要非对角单元；不能只看颜色深浅。
- **PR/P/R/F1 curve**：是阈值变化的整体行为，不要从 TEST curve 重新选 operating point。
- **t-SNE**：本轮未生成，因为仓库没有冻结逐样本 embedding 缓存；为了报告好看而重新推理不必要。即使未来生成，也只能是 visualization-only，不能代替 macro F1。
- **three-seed plot**：重点是 paired direction 和 std，不是挑最好 seed。
- **Stage2 grid**：是历史冻结网格的重绘/复用，绝不是新阈值搜索。
