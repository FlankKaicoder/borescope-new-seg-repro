# EXP18 GPU 工程协议草案

本草案供独立审查。授权状态为 `NOT_GRANTED`。H200 和独立 H100 备用配置均维持 `lambda_state=null`，正式训练、CUDA 初始化、真实模型和张量加载、真实前向/反向/更新、VAL、TEST 预算均为 0。未来工程运行需独立签署阶段预算、绑定代码与数据 SHA，并与正式训练隔离。

## 分阶段预算候选

## 输入和真实计算图

- 核验单 GPU 拓扑、驱动/显存/可用空间，固定 Torch/vision/Ultralytics 与实际源码 SHA，预先核验 COCO 权重和 TRAIN 资产身份。历史 RTX 2080 Ti 约 22 GiB 仅作预算依据。
- 已封存 R5 尾段 A 包选 2059、2060、2064、2068、2070、2071、2072、2076、2079 共九批。依次核对归档、文件、native 六张量组合、identity/trace 和 matching SHA。独立 CPU 准备另行获准后，从现有 N/Valid 与轨迹重建对应 N，匹配封存 N 回放指纹。本阶段没有重新读取像素。未来最多 9 个旧 A 包加载和 9 个新 TRAIN 包回读，训练包张量加载与模型加载分列。
- 初始化比较 COCO transfer、七类原生初值、J1 投影、两状态头初值、全局 RNG 和 BN。Smoke 固定 2071（空）、2064（N 复用）、2079（尾批），三臂各做 FP32/AMP。常规 18 A、8 N。另在 2064 两种精度各一次 A/A，合计额外 2 A、2 N。Component 为 18 主、8 辅、2 A/A、4 个预先选定 BN 局部 VJP，对应 32 次。Joint 只有常规 18 次。
- 检查 S、权重、A/N 槽、P3、Connected BN 导数、True/Shuffled 只改 N 索引、A 的 BN 一次更新、N 不写 BN/RNG。用诊断系数 1 检查线性叠加，正式 λ 仍为 null。候选容差为 FP32 独立 VJP/联合梯度相对 L2 ≤ 1e-4，AMP 对 FP32 的损失相对差 ≤ 1%、梯度相对 L2 ≤ 5%、余弦 ≥ .99。身份、游标和非更新路径用严格字节相等。容差须随阶段审批冻结。

## 共同 λ 标定规则

固定 TRAIN 批 2059、2060、2064、2068、2076、2079。模型状态为 J1 MASTER E5、E50、E100，fresh COCO 作为额外初始状态诊断。固定白名单校验历史文件 SHA 后只恢复 MASTER/BN/投影，统一使用独立初始化的同一状态头，不恢复历史 optimizer 或训练位置。

每个状态×批次建一个共同 FP32 A/N 图，共 24 图。每图采集主梯度、True 辅梯度、Shuffled 辅梯度各一次，使用裁剪前、未 scale 的值。主梯度为 `grad(YOLO + 8*SupCon)`，辅梯度为 `grad(A1)`。在 trainable Backbone `model.0..10` 及 Neck `model.11..16` 分别算 FP64 L2 比 `q = norm(aux)/norm(main)`，排除状态头、投影、冻结参数。记录方向余弦与完整梯度域诊断。

每个历史状态和臂对六个 Backbone 比取中位数 `m`。共同区间下界为 `max(0.01/m)`，上界为 `min(min(0.03/m), min(0.10/q))`。上界的逐批每域约束含两臂、三历史状态和 fresh 诊断。候选从 `0.02 / geometric_mean(m)` 投影到共同区间，并确认存在满足所有约束的正 FP32 值。主 Backbone 零梯度、任一历史块的中位数为零、非有限值、区间为空都 HOLD。辅助零保留在中位数内，该项无逐批上界约束。Neck 主辅均零记录为空域约束，主零辅正则 HOLD。VAL 不参与标定。

标定写候选和回执，正式配置保持 null。经另行获准进入临时更新时两辅助臂使用相同候选。候选阈值描述固定案例的梯度尺度，正式训练效果由后续独立评价决定。

## 临时状态、长段恢复及停止

- 先用 J1 在 2070／2071／2072 做 3 次临时更新，保存初始和更新后的 4 份状态，建立完整 AdamW/EMA 序列化样本。标定后 J1 从第一步保存点重做末两步。True、Shuffled 各跑三步再恢复重做两步，共 12 次更新、6 次 N prefix。短探针采用 AMP，保留 FP32 Smoke 参照。探针逻辑步与源账本步号分离。
- 状态计量复用这些探针已保存文件。Checkpoint 写入自动读回为额外张量加载：计量 4，短恢复 14，加显式恢复 3、COCO 3、J1 参考加载 3，共 27 次模型/状态反序列化预算。三臂分别记录有效单状态字节、读回 SHA、临时峰值、时间和每类实际 dtype。探针状态用工程专属产物标记，正式恢复拒绝接收。
- V2 长段恢复有最多 105 次额外物理训练更新的单事件上限。此次没有长段 GPU 授权。真实逐位恢复须单独预注册连续/中断对照、适用环境、各臂和全预算。AMP/CUDA 漂移须明确覆盖的张量、最大偏差和科研影响，并 HOLD 等待审查。短段或合成恢复通过不能作为完整区间的验证结果。
- 真实 VAL、正式训练与 TEST 未进入工程预算。正式阶段须另行通过 GPU Smoke、数据重建、共同 λ、恢复和容量 Gate。未来已批准的 H200 评价合同仍为每臂 40 个事件、160 pass，三臂 480 pass，采用同 pass 逐图记录。当前阶段结束后等待独立审查。
