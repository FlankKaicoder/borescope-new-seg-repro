# EXP18 三臂实验设计与资源恢复后的验收顺序

2026-11-25。当前只做设计、代码整理和已有证据交接；用户要求等服务器算力可用后再测试验证。本文不授予GPU、模型、VAL或正式训练预算。

## 1. 要回答的问题

首轮分别回答两个问题：增加状态排序监督是否改善现有J1；正确的A/N对应是否提供额外价值。J1在历史三个seed方向为正，R5恢复正常推理后Seed42仍低于J1；扩大相对距离不自动意味着七类检测获益，因此保留同期三臂。

| 实验臂 | 原图主任务 | 状态监督 |
|---|---|---|
| J1 | 七类YOLO + SupCon8 | 无状态头、无N前缀 |
| A1-True | 与J1相同原生输入和任务 | 在共同可交换集合S中取自身N |
| A1-Shuffled | 与True相同输入和任务 | 同一S、同一N前向，仅重排池化后N索引 |

必须同时报告True−J1、True−Shuffled、Shuffled−J1。True高于Shuffled但不高于J1，只能说明错误对应的代价；两辅助臂都优于J1而彼此接近，不能证明正确伙伴有独立增量，也不能推断未训练的A0有效。

## 2. 已冻结的条件

- 首轮Seed42、fresh COCO初始化；H200/4200更新为默认候选，H100独立备用，不中途切换或单臂延长。正式训练仍未授权。
- 主A使用全部668 TRAIN、七类原生损失及原J1投影/SupCon，不能限制到辅助集合S。N不作为检测背景图，不进入七类YOLO损失。
- raw P3 layer16、64通道、stride8。原生stride4实例mask经2×2覆盖平均形成80×80权重，池化后L2；不放大小ROI、不裁掉Invalid再重归一化。
- 共用无偏置64→1线性头、独立RNG非零初值，固定温度1；A1为`softplus(-(sA-sN))`。A0仅作数学参照，B/C不进入首轮。
- 沿用R5整批A逐层通道均值/有偏方差的connected导数。N保持自己的图像、增强、ROI和当前A批统计绑定，完成前向与池化后再重排。
- True/Shuffled共同集合、N槽、权重与初值相同。类别等权、类内区域等权；空S时state head的MASTER、AdamW和EMA-head冻结，主任务正常更新。
- 全局clip10、原生optimizer/EMA、数据流与随机数规则保持统一。恢复分开保存global/head活动计数。

闭合错配要求同批、同类、同修复版本族、异来源组；原生标签float32归一化坐标的面积占比之比在1/2–2；增强后格点同档（1、2–4、>4）且数量比在1/2–2。选择最大共同闭合集合，无固定点、N不重复，不用普通左右匹配后取交集替代。

## 3. 现有预演对设计的约束

首轮21批K502、S92，严格匹配只保留18.33%；Corrosion为191→21，Tears为39→6，Tip curl没有直接A/N监督。全局S为85个来源组，不应把重复epoch曝光当独立样本。

该结果只能描述首轮，不能外推完整4200批。优先等待全轨迹的每类/版本/尺度/格点/来源集中度和伙伴多样性报告。若关键类别覆盖不足，提交独立方案审查；不得为了覆盖临时放宽当前caliper、版本族或来源组限制。

正确配对可以消除来源加性基线；配对损失优势本身不证明学到缺陷独有形态。现有N来自修复，状态与生成域仍耦合。来源组是近重复控制代理，不能写成真实发动机/工件身份。

## 5. 必须留待实测或审查的量

- **λ**：两辅助臂共用，不能照搬Pair4，不按VAL搜索。TRAIN梯度标定的状态、目标比例、数值容差、操作上限及拒绝条件在GPU阶段另行冻结；当前没有正式数值。
- **GPU行为**：真实网络的初始化一致性、AMP数值差异、整批统计连接、N不写buffers、全局裁剪和真实恢复，均不能由合成图推出。
- **容量**：不可变epoch包、逐步完整恢复和逐图预测需要实测字节上界；没有删除/覆盖授权时，45GiB不能视为已满足三臂留存。
- **成本**：无卡0.5CPU下单轮约2分钟，H200预计6–8小时仅为旧配额估计。GPU时间、显存、数据等待和VAL开销需实测，不承诺开卡自动改变CPU配额。
- **科学Gate**：R5独立科研审查和EXP18的覆盖/机制审查保留，不自动记PASS。
