# EXP18 CPU 覆盖审查

已审查 1 个已提交 epoch、21 个原生批次。闭合置换、合法边及逐行权重边际均通过。

K 候选曝光 502 次，S 实际匹配曝光 92 次。这两项均为重复训练曝光；唯一 Polygon 和来源组见逐类表。

K 不要求 B；S 的每个异组同类伙伴本身也提供一个真实 B，因此 S 的 no-B 数必为零。面积与 P3 约束漏斗统计的是逐级具有合法伙伴的行；最终 S 还受闭合最大指派限制。

原 R5 交集和旧层级权重仅在原记录可恢复且数据精确对齐的前 2,100 步计算。缺失记录明确标 UNKNOWN，后 2,100 步不属于历史分母。辅助权重按每批有效类等权、类内保留 Polygon 等权；组集中度单独报告。

本报告只读元数据，不含图像、模型或真实 checkpoint。结构验收通过不代表覆盖足以支持科研主张；科学覆盖审议、GPU smoke、λ 和正式训练授权仍待后续 Gate。
